# Changelog

Repository releases describe sanitized public snapshots. They may lag the living private Parliament, which remains the institutional Source of Truth.

## [1.2.0] - 2026-11-23

### Added

- SOP Packages and Runtime Skills: the shared package shell, departments, reserved shells, and the intake, package, first-job, evolve, audit and release lifecycle.
- Multi-Agent Fleet and Hand-offs: officer identity separated from runtime, a skill-set home per officer, verified capabilities, mission packets, and boot and recovery routing.
- Ten field-test articles in the public Constitution (IX to XVIII), clearly marked as candidate status.
- Two operational rights: distinguishing chat continuity from memory, and a proposed explicit command state.

### Changed

- Start Here glossary and reading order route the new documents.
- The validator can load extra blocked patterns from a local, untracked file, so private names never have to appear in the public script; it also checks the v1.2 routes.
- Authorship line made role-neutral.

### Compatibility

No existing public procedure changed incompatibly. New documents extend the v1.1 architecture.

## [1.1.0] - 2026-08-13

### Added

- Decision dockets for connected ambiguity that requires human judgment.
- An incident-to-SOP lifecycle with field verification, human ratification, and reserved-shell continuity.
- Cold-reader terminology as a context-compression control.
- Public decision-docket and SOP-department-shell templates.
- A public snapshot declaration and automated repository validation workflow.

### Changed

- Replaced nonportable Obsidian wikilinks in Start Here with explicit GitHub-compatible Markdown links.
- Expanded the architecture and institutional-compounding routes to distinguish candidate material, HOLD states, ratification, and reserved shells.
- Strengthened validation to reject unsafe content, unresolved wikilinks, broken links, and release-identity drift.

### Compatibility

No existing public procedure changed incompatibly. New documents extend the v1.0 architecture.

## [1.0.0] - 2026-08-13

- Initial sanitized public snapshot of Parliament's governance, Source-of-Truth controls, Human-AI Sandwich, Production Wheel, Four-Pass Approval Workflow, templates, and Obsidian-compatible structure.
