# Start Here

Parliament is an operating architecture for people who work with multiple AI systems and need those systems to remain aligned, inspectable, and useful across conversations.

## Cold-reader glossary

- **MDS:** MarkDown Studios.
- **Parliament:** The governed Markdown system that stores institutional law, operating procedures, and recovery routes.
- **SOT:** Source of Truth, the single controlling source for one governed scope.
- **Derivative:** A downstream expression that must follow its SOT.
- **Commission:** An executable brief defining objective, evidence, scope, authority, deliverables, and acceptance gates.
- **Cold reader:** A person or agent entering without reliable recent context.
- **Approval gate:** A named decision point with Pass, Send Back, or Escalate outcomes.
- **Graveyard:** Preserved inactive history, never current authority.

## What Parliament is not

It is not a claim that AI agents possess human memory, independent legal authority, or consciousness. It is an external inheritance and governance system made from inspectable files. The system becomes more capable because future work receives better context, evidence, procedures, and safeguards.

## Core principle

> AI expands the possibility space. Humans collapse it into direction and action.
