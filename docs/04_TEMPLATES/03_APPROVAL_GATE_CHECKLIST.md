# Approval Gate Checklist

## Before production

- [ ] The problem and purpose are explicit.
- [ ] The SOT is resolvable.
- [ ] The starting state is evidence-based.
- [ ] The end state is observable.
- [ ] Scope and exclusions are explicit.
- [ ] Authority boundaries are explicit.
- [ ] Acceptance tests are named.
- [ ] Missing human taste decisions are resolved or escalated.

## At every handoff

- [ ] Original commission accompanies the return.
- [ ] Evidence is distinguished from interpretation.
- [ ] Assumptions are visible.
- [ ] The specialist stayed inside the assigned lane.
- [ ] The derivative still matches the SOT.
- [ ] The return receives PASS, SEND BACK, or ESCALATE.

## Before delivery

- [ ] The real delivery artifact was inspected.
- [ ] Links, names, metadata, formats, and dimensions are correct.
- [ ] No placeholder or private data remains.
- [ ] The final artifact matches its Locked Cut.
- [ ] Human publication authority is explicit.
