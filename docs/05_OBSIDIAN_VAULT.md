# Obsidian Vault Guide

This repository is an Obsidian-ready Markdown vault.

## Open it

1. Clone or download the repository.
2. In Obsidian, choose **Open folder as vault**.
3. Select the repository root.
4. Open `README.md` or `docs/00_START_HERE.md`.
5. Use Graph View to inspect the governance and workflow links.

## Why Obsidian matters here

Finder exposes the human-readable hierarchy. Obsidian exposes the relationship graph. The two surfaces serve different retrieval modes but share the same Markdown sources.

## Link law

The graph only knows what is linked. Every important relationship should be visible through a Markdown link or wikilink, but no link may replace the explicit SOT declaration for authority.

## Included configuration

- automatic internal-link updates;
- relative link formatting;
- Graph View and backlink tools;
- workspace files excluded from version control.

## No plugin dependency

The core project works with plain Markdown and Obsidian's core features. Community plugins are optional rather than architectural dependencies.
