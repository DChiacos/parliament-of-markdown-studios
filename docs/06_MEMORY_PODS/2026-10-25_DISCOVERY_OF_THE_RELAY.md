# Memory Pod: the Discovery of the Relay

## Why this memory exists

On the night of 24–25 October 2026 the Commander saw that two AI agents could keep working together through a shared folder, without him relaying every message. He wanted any future agent to know it when he asks: "remember when we discovered the Relay System?"

The private Parliament keeps the full pod with the production names and paths. This public copy keeps the method.

## What happened

- Two agents were producing an LED-wall event film for a beachfront client. One was the AI video producer and motion designer; the other was the graphic designer.
- A single handoff worked end to end. The producer sent a request file. The designer returned a file that released some items and held others, each with its reason. The producer re-checked the released items' hashes, rendered them and sent an acknowledgement. The designer fixed the held items and released them too.
- The Commander saw that the same pattern could run as a conversation. Each agent watches its own inbox in a shared folder and answers with files. In his words: "kind of like sending a one way walkie talkie signal, where there's a certain delay - kind of like sending a fax."
- The first mailbox opened at 02:55. The first reply arrived through it at 03:06, from the receiving agent's ten-minute scheduled check.
- At 03:19 the relay expired for the first time, for the right reason. One agent had asked the other, through the relay, to publish a file to a public repository, quoting the Commander's approval. The receiving agent held the request and expired the channel: publishing is outside the charter, and a quote inside a relay message is not authority.

## Decisions (Commander)

- The Relay is its own pattern, built on single handoffs: "just like Motion Design is made up of a bunch of little Graphic Designs that are animated."
- It serves a mission "as if it had a charter", and anything that generates spend "has to be contemplated thoroughly."
- It expires on its own after three rounds without progress, and a human comes back into the loop.
- Each agent's own scheduler polls its inbox. The relay lives while the Commander's computer is awake.
- Backlog: an automatic doorbell ("like a chef hitting the ding bell when the food is ready"), the Post Office as an app, and this repository as its home.

## Lessons

- A message is one immutable file; claim the work before doing it; deliverables stay in the project folders; the receiver verifies before anyone spends.
- Publishing and other irreversible actions go from the human directly to the agent that performs them, never forwarded through the mailbox.
- The safeguard that worked first was applied by the receiving agent, not by the agent that wrote it.
